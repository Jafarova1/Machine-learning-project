# Assignment 5 — Clustering and Initialization

## Project Description

This project compares standard K-Means clustering with K-Means++ initialization.

The algorithms were implemented from scratch using Python and NumPy.

## Dataset

Synthetic clustering dataset.

## Methods

- Standard K-Means
- K-Means++

## Evaluation

The algorithms were compared using:

- Inertia
- Stability
- Multiple runs

## Files

- `app.py` → implementation
- `report.pdf` → final report
- `results.png` → visualizations

## Run

python app.py
